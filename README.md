# DevPortfolio 

A personal, interactive web portfolio for Pranavi Saxena[cite: 1]. This project showcases technical skills, educational background, and featured projects in a modern, responsive layout.

## Features
* **Theme Toggle:** Switch between light and dark modes smoothly[cite: 2].
* **Dynamic Typing Animation:** Hero section features an automatic typing effect displaying different roles[cite: 2].
* **Project Filtering:** Instantly sort portfolio projects by category (All, Web, Python/DSA)[cite: 2].
* **Responsive Design:** Adapts beautifully across desktop, tablet, and mobile devices using CSS grid and flexbox[cite: 3].

## Technologies Used
* HTML5[cite: 1]
* CSS3 (Custom Variables, Animations)[cite: 3]
* JavaScript (DOM Manipulation, LocalStorage)[cite: 2]
* FontAwesome Icons[cite: 1]
